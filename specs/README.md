# Specs

This project uses **spec-driven development**: every feature is specified, designed and
planned in writing before it is implemented. Each feature lives in its own folder
`specs/NNN-short-name/` with `spec.md`, optional `ui.md`, `design.md`, `tasks.md` and `review.md`.

Workflow: Spec → (UI design) → Plan → Implement (phase by phase) → Review.
Every step ends with a review by you; an artifact is approved when its frontmatter says
`status: approved`.

Each feature is developed on its own git branch `feature/NNN-short-name`. Every approved
step is committed there locally; when the feature is done you choose: push & pull request,
merge locally, or leave as is.

Start a new feature in Copilot Chat by selecting the **sdd-orchestrator** agent (full
workflow with pauses) or **sdd-spec-writer** (only the first step).
